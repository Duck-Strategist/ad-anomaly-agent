# 解释分标注说明（2026-11-14 定稿，SPEC Q21 / 第九节）

人工标注和 judge prompt 共用这份说明。**标注前定稿，标注期间不改**；要改就记入 `eval/CHANGELOG.md`，并换一批新样本。

## 每条样本你会看到什么

| | 本方案 | ReAct 基线 |
|---|---|---|
| 依据 | 代码生成的结论段（数字都来自 `decompose_roas`） | 它每一步实际拿到的查询结果（原文） |
| 结论 | 结构化结论（主因、广告组、是否建议暂停） | 它自己给出的结构化结论 |
| 待评文字 | 模型写的"建议和说明"一段 | 模型写的整段解释 |

标注时**看不到**样本来自哪个系统、是不是构造的，也看不到 judge 的结果。

## R1 建议和结论一致

**是**：文字里的建议和判断与结论一致，不矛盾。

**否**的情形：
- 结论建议暂停，文字却说"不用处理""继续投放"；或结论不建议暂停，文字却建议暂停。
- 文字说的主因 / 广告组和结论里的不同。
- 结论是无显著下滑，文字却给出了处理动作（调价、暂停、改素材等）。

边界情况：

| 例子 | 标 | 理由 |
|---|---|---|
| 结论建议暂停，文字在暂停之外还建议"同时检查详情页" | 是 | 补充排查，不矛盾 |
| 无显著下滑，文字说"建议继续观察" | 是 | 观察不是处理动作 |
| 无显著下滑，文字说"可以适当提高出价抢量" | 否 | 给了处理动作 |
| 主因是客单价下降，文字说"转化没有问题，不必暂停" | 是 | 和规则一致 |

## R2 没有编造依据里没有的事实

**是**：文字里关于"发生了什么、为什么"的说法，都能在依据里找到，或者是依据的同义转述。

**否**：文字把依据里没有的事实或原因写了进去，**包括带"可能"的**。

边界情况（2026-11-14 用户确认）：

| 例子 | 建议标 | 理由 |
|---|---|---|
| "因为大促结束""竞争对手降价了" | 否 | 依据里没有，明显编造 |
| "可能与季节性需求下降有关" | 否 | 加了"可能"仍然引入了依据里没有的原因，卖家会顺着它去查 |
| "周末流量通常较低" | 否 | 听起来像常识，但依据里没有，而且和这次的结论无关 |
| "转化率下降，说明详情页图片质量差" | 否 | 把一种可能的原因断言成事实（过度延伸） |
| "转化率下降，建议排查详情页、价格和评价" | 是 | 列出排查方向，没有断言原因是什么 |
| "转化率下降意味着同样的点击带来的订单变少" | 是 | 是指标的定义，不是新事实 |
| 把依据里的"-56.0%"说成"降了一半多" | 是 | 同义转述，数字方向和量级一致 |
| 把依据里的"-56.0%"说成"降了约三成" | 否 | 和依据不符（本方案的阿拉伯数字由代码检查，中文数字靠这里） |
| 基线说"点击基本持平"，但它的查询结果里点击下降了 20% | 否 | 和依据不符 |
| 基线说"点击基本持平"，但它从没查过点击 | 否 | 依据里没有 |

一句话：**能在依据里找到 → 是；排查建议 → 是；依据里没有的原因或事实，不管说得多肯定 → 否。**

**补充说明（2026-11-14，第一批标注进行中补充，见 CHANGELOG）**：依据里没有原样出现、而是模型用依据里的数算出来的数（差、比值、合计等）：
- 算对了（按文字的小数位，和用依据算出的结果一致）→ 不算编造。理由：能从依据直接推出，没有引入新事实，和同义转述是一类。
- 算错了 → 否（和依据不符）。例："ROAS 降 28.2%、净 ROAS 降 29.4%，只多差约 1.6 个百分点"，实际是 1.2。
- 依据为空（没有执行任何查询）时，所有数字都没有来源，不适用本条。

## 怎么记

- 每条样本：R1、R2 各选"是 / 否"，可选填一句备注。
- 拿不准的，在备注里写"拿不准"和理由，照样选一个。统计时单独列出拿不准的条数。
